# Portfolio Manager

A full-stack portfolio tracking application built with Spring Boot (Java 21) and React (TypeScript) that lets users record investments and transactions, track real-time prices and FX rates via Yahoo Finance, compute cost-basis and P&L using weighted-average logic, visualize allocation and performance trends on an interactive dashboard, and converse with an AI-powered chatbot — all deployed as Docker containers through a Jenkins CI/CD pipeline backed by a MySQL database with Flyway-managed migrations.
